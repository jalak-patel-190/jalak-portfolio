Case 04 · Gujarati multi-format distribution

One film, multiple release formats

How Gujarati catalogue assets were distributed through full releases, serialised parts, Shorts, and Facebook cuts, with tenure views tracked separately from lifetime catalogue.

Context

A film can have more than one useful release format

Full releases, serialised parts, Shorts, and Facebook cuts each reach different watching habits. Treating them as one upload path wastes formats that the same title can support.

Problem

A single upload does not use every available format

When a title only goes out as a full film, the parts, Shorts, and social cuts that could keep the same story working across platforms never get built into the plan.

Strategy

Match the format to the job

Plan which format does which job: full release for complete viewing, serialised parts for return visits, Shorts for discovery, Facebook cuts for recovery and alternate reach. Keep tenure performance measurable against that plan.

Evidence

Rakhewal: one film, multiple tracked outputs

Rakhewal shows how one title was run across formats during tenure, with analytics kept as the operating surface rather than a single vanity total.

Results

One title, multiple tracked distribution outputs

This case documents the packaging system and the evidence surfaces. Tenure views for specific films are reported where the archive supports a clear window; lifetime catalogue is not mixed into those claims.

Takeaway

Distribution is a packaging decision as well as a publishing decision

Format choice is part of the strategy. When full, parts, Shorts, and Facebook cuts are planned together, the same title can work across platforms without treating every surface as a copy of the same upload.
