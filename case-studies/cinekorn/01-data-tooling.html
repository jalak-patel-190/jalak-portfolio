Case 01 · Data tooling

Data bottleneck and AI-assisted tooling

Using an AI-assisted Python workflow to classify 6,000 to 8,000 rows, with human checks and interpretation.

Context

Catalogue volume blocked decisions

Film catalogue work at this scale required consistent classification before distribution choices could be defended. Manual review alone could not keep pace with the row volume.

Problem

Too many rows, not enough structure

Without a repeatable classification path, the same titles were hard to group, prioritise, and measure across channels.

Strategy

AI assist with human ownership

Build a Python workflow that proposes labels, then keep human review on ambiguous or high-stakes rows so the system stays accountable.

Evidence

Workflow in practice

Takeaway

Speed without giving up judgment

The goal was not full automation. It was a defensible way to move thousands of rows into a structure the distribution work could use.
