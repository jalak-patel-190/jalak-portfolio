Case 01 · Cinekorn Entertainment

Turning a Manual Data Task Into a Content Decision

Content work does not always begin with a creative brief. Sometimes it begins with a messy spreadsheet.

~6,000–8,000 rows
2 days to finish
AI + human review workflow

Context

Where the work started

Early in the Cinekorn role, I received multiple files containing roughly 6,000 to 8,000 rows of data that needed to be sorted and classified by tier before the information could support further analysis.

The task itself was not complicated. The problem was the volume of repetitive work. Manually reviewing thousands of rows would have taken several days and added little value beyond completing the classification.

Problem

Organise data without wasting judgment time

The data had to be organised correctly before it could support any useful decision. There were two paths:

  • Do the entire task manually, or
  • Remove the repetitive part while keeping human review over the final output

The second option made more sense. The challenge was using AI without treating AI output as automatically correct.

Strategy

The decision

I used Gemini to help generate the Python workflow and ran the process through Google Colab.

AI’s role was limited to building the repetitive processing workflow. Responsibility stayed with me:

  • Understanding what the data needed to be classified into
  • Defining the required output
  • Running the workflow
  • Checking results and correcting issues
  • Making sure the final dataset was usable
Goal was not “use AI.” Goal was remove unnecessary manual work while keeping control over the result.

Execution

How the workflow ran

Raw files → AI-assisted Python → Classification → Manual check → Usable dataset

Instead of working through every row by hand, repetitive classification ran through the workflow. Output was reviewed before use. The complete task finished within two days.

Results

What changed

Approximately 6,000–8,000 rows processed and classified within two days.

The immediate result was faster data preparation. The more useful result: time moved away from repetitive sorting toward work that required judgment — understanding what the data meant and how it could be used.

Takeaway

What this showed

AI was useful because it solved a specific bottleneck. I do not see AI as a replacement for judgment. I see it as another production tool.

The important skill is knowing where it can remove repetitive work, where it needs checking, and where the decision still belongs to the person doing the work.
