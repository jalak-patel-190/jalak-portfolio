Case 04 · Gujarati multi-format

One film, multiple release formats

One film distributed through full release, serialised parts, Shorts, and Facebook cuts, with tenure views tracked separately.

Context

One title, many surfaces

A single Gujarati film could be packaged for long-form YouTube, serialised cuts, Shorts, and Facebook without treating every format as the same post.

Problem

Format choice is a distribution decision

Uploading only the full film leaves reach on the table. Each format serves a different entry point into the same title.

Strategy

Design the release system

Plan full release, parts, Shorts, and Facebook cuts as one distribution system, and measure tenure views so catalogue total is not confused with new work.

Evidence

Analytics and comparison

Takeaway

What this showed

Multi-format distribution is a system: same title, different entry points, honest tenure measurement.
